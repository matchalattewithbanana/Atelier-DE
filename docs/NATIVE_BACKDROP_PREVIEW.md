# Native backdrop effect comparison

Native themes includes a collapsible comparison of focused window, panel, dock and widget backdrop blur and opacity. Each sample places a sharp synthetic reference beside its filtered and tinted counterpart. The radius is bounded to 0–16, with blur inactive for opaque surfaces. Window opacity composites the sample client as a group, whereas shell backgrounds are translucent independently of foreground text. The preview uses a fixed 160×48 RGB pattern and separable CPU box filtering, not the compositor's GPU filter. It shows configured effects independently of runtime pass budgets, output capability, surface geometry and per-app overrides. The existing validated draft, review and apply workflow is unchanged. No new dependencies or schema changes. Tests cover effect gating, identity and edge smoothing, and offscreen Cairo rendering.
