# Native built-in theme library

Native Themes offers six bundled portable visual presets: Midnight, Blue Glass, Daylight, Sakura, Forest and Monochrome Contrast. The catalog is shared by Settings and other future native clients. Filter by name, color or style and browse a separate candidate illustration before selecting Load preset into draft. Loading deliberately replaces the full portable draft (palette, spacing, icon sizes, borders, corners, shadows, blur and opacity), but does not write files or apply settings. The existing Review draft and Apply reviewed theme operations remain required, with stale-profile protection and previous-version recovery.

Presets use the existing Material color generation pipeline and validation. Monochrome Contrast requests high-contrast opaque colors; Blue Glass uses experimental native backdrop effects. These are portable visual presets, not full GTK application themes, installed rice packages or wallpaper collections. Applying one preserves local wallpaper, dock pins/visibility, widgets, notification preferences, cursor and reduced motion. They can be exported using the existing portable JSON format. Search and candidate preview do not modify the active draft. Actual contrast over translucent backgrounds and physical compositor rendering still require acceptance. Tests cover all preset round trips, local preference preservation, search and contrast/effect policy.
