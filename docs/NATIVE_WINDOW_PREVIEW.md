# Native window preview

The Window appearance editor includes an offline two-tile grid illustration of draft inner/outer spacing, focused/unfocused border colors and width, corner radius and approximate ambient shadow radius/opacity. Switch the sample focus locally to compare styles. The preview also reflects the loaded profile's client opacity; this page does not edit opacity. Invalid border color text uses a labelled fallback preview and remains subject to existing save validation. The renderer uses a synthetic background, fixed geometry and bounded Cairo drawing; it does not simulate actual compositor blur, per-app overrides, maximize/fullscreen or tiny-output allocation. Draft rendering and reviewed persistence share the same field collection. No live compositor state, configuration schema or dependencies change until the user explicitly saves the existing appearance preferences.
